# Registrar-se i obtenir el teu codi personal
{: .no_toc }

Casos d'ús <span class="uc-id">S1</span> registrar-se, <span class="uc-id">S2</span> corregir les teves dades, <span class="uc-id">S9</span> veure qui està registrat.
{: .fs-3 }

1. TOC
{:toc}

## Registrar-se

Obre **Registra'm** (o `/students/register`) i omple els camps que ha triat el teu professor: normalment el teu nom, el teu correu i alguna dada de la teva màquina.

{% include screenshot.html file="students-register" alt="Formulari d'alta" %}

{: .tip }
Si un camp s'omple sol amb la teva IP, registra't **des de la màquina que s'avaluarà**. Si no, demana al teu professor que el corregeixi.

Si alguna cosa està malament, el formulari et diu quin camp has de corregir:

{% include screenshot.html file="students-register-errors" alt="Formulari d'alta amb errors" %}

- Els camps obligatoris no poden quedar buits.
- El correu ha de semblar un correu.
- Els valors escrits només admeten lletres, números, espais i `. _ - @ : /` (excepte les contrasenyes), fins a 100 caràcters.
- L'adreça d'una màquina no pot ser el mateix ordinador del panell.

## El teu codi personal

En registrar-te reps un **codi personal** i la teva adreça personal:

{% include screenshot.html file="students-registered" alt="Alta completada: el codi personal" %}

**Guarda el codi**: el necessites per executar el teu test i veure els teus resultats. Si el perds, demana'l al teu professor, que veu tots els codis. La teva pàgina personal és `/students/<codi>`; la pots desar als marcadors.

## Corregir les teves dades

Si has escrit alguna cosa malament, obre la teva pàgina, canvia els valors a **Les meves dades** i prem **Desa les meves dades**. Els valors anteriors se substitueixen. Deixa buit un camp de contrasenya per mantenir l'actual.

## Qui està registrat

L'inici d'alumnes llista els noms de tots els registrats (sense codis ni altres dades), perquè comprovis que hi ets. El teu professor pot amagar aquesta llista.
