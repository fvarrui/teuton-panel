# Stack

## Language

- Ruby ≥ 3.2.8 (Standard configured for 3.2)

## Runtime

- Thor (CLI)
- tty-prompt (terminal prompts)
- Sinatra 4 (web)
- Rackup + Puma (server)

## Development

- Bundler, Rake
- test-unit
- Standard (lint)

## Data

- YAML: the panel's `teuton-panel.yaml` and Teuton's config files (`config.yaml`, `config.d/`)

## Distribution

- RubyGems gem, MPL-2.0 license
